# checkers-engine
CPSC 481 Group Project - King Maker Checkers Engine

# Dependencies
- Tkinter
```
pip3 install tk
```
# How to Run
```
python3 -m gui.py
```
Or using uv:
```
uv run gui.py
```

# Statistics:

statistics.py contains the code for collecting simulated game data for using game win percentages as a heuristic.
